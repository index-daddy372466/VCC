# Search Engine Optimization

## 2025.12.07

1. What are Meta Tags?
Meta tags are HTML code snippets placed in the <head> section of a web page that provide information to browsers and search engines, such as the page's description and keywords. They are invisible to site visitors but are crucial for SEO and social media, as they help search engines understand and rank content, and influence how a page is displayed in search results and on social media platforms. 

2. How can this work for my site?
Meta tags function by providing metadata about an HTML document, which is data about data, to browsers, search engines, and other web services. These tags are placed within the <head> section of an HTML document and are not visible on the webpage itself but are read by machines.

3. Can I see my Meta tags?

   Your updated meta can be accessed in the __index.html__ file, or view below.

   ```
    <meta name="author" content="Leland Bassie">

    <meta name="description" content="Seeking a Certified Rehabilitation Counselor in West Palm Beach? We offer specialized counseling for trauma, disability, and career recovery. Start your journey to healing. Call now">

    <meta name="robots" content="follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1">
    
    ```

   __Key Take Aways__:

   <em>name = "robots"</em>

   <em>[max-image-preview:large, max-snippet:-1, max-video-preview:-1]</em>

   This will help you improve your website’s appearance on Google Discover.

   This rule instructs Google to display large image previews, unlimited text snippets, and full-length video previews in search results, which can greatly help improve your CTR in Discover.
